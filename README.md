# Hafif sürümleri

Hafif çevrimdışı not defterinin kurulum dosyaları. Bu depoda yalnızca sürümler var: kaynak kod ve hiçbir not yok.

En yeni sürüm: [Releases](https://github.com/volkanyilmaz109-prog/hafif-surumler/releases/latest) → `Hafif-Kurulum-x.y.z.exe`

Kurulum dosyası kod imzalı değil; Windows SmartScreen uyarı verirse **Ek bilgi → Yine de çalıştır**.
Kurulu Hafif yeni sürümleri buradan kendisi bulur.
